# 弹幕矩阵机 PRO v4.2 (开源版)

## 简介
这是一个基于 Selenium 和 Python 的多账号弹幕矩阵控制台。
原版去除了加密和付费逻辑，完全免费分享给大家。

## ✨ 特色功能
- **多开管理**：支持无限添加 Edge 浏览器节点。
- **智能防折叠**：内置随机表情 + 短句后缀算法降低弹幕重复被折叠。
- **省流模式**：主账号保留声画，小号自动静音暂停。
- **弹幕间隔参数调整**：支持自定义弹幕口令刷屏速度,单位效率为1=1秒.
- **悬浮窗控制**：F8 快捷键一键启停。	ESC+~快捷键关闭软件.

## 使用方法
1. 安装依赖: `pip install -r requirements.txt`
2. 运行: `python main.py`
3. 点击 "添加节点" 登录你的账号。
4. 启动矩阵，享受弹幕轰炸。
